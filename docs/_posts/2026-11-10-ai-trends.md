## 📌 오늘의 한 줄 요약
더 강한 모델이 나와도 핵심은 **어디에 쓰고, 사람은 무엇을 이해하고 있을지**를 정하는 것입니다.

## 🎯 활용 Best Practice

### 모델은 "계층"으로 써라: 기본 Opus, 어려운 일만 Fable (Anthropic, 11/9)
- Anthropic은 Fable 5.2를 발표하며 대부분의 코딩·지식 작업은 Opus 5.5로 시작하고, 가장 크고 열린 과제만 Fable/Mythos로, 단순 작업은 Sonnet·Haiku 5.5로 내리라고 안내했습니다. Fable 5.2는 작은 모델이 막힐 때 묻는 **Advisor**나 일을 나눠 주는 **Orchestrator** 역할로도 쓸 수 있다고 밝혔습니다.
- **적용 팁:** 기본 모델을 하나 정하고, "막혔을 때만" 상위 모델에 묻는 경로를 둡니다. Claude API의 advisor tool(베타)이 이 패턴을 지원합니다. 효과는 작업마다 다르다고 문서에 적혀 있으니 자기 eval로 확인하세요.
- 🔗 [Anthropic 발표](https://www.anthropic.com/claude-fable-and-mythos-5-2) · [Advisor tool 문서](https://platform.claude.com/docs/en/agents-and-tools/tool-use/advisor-tool)

### 에이전트가 쓴 PR 설명은 접고, 위에 사람 요약을 써라 (Simon Willison)
- 에이전트의 PR 설명은 정확하지만 길어서 아무도 읽지 않습니다. 읽는 데 쓰는 시간이 쓰는 데 든 시간보다 길면 성의 없어 보인다는 지적입니다.
- **적용 팁:** 맨 위에 직접 쓴 짧은 소개(+스크린샷)를 두고, 에이전트 원문은 `<details><summary>Claude Opus 5.5 Medium</summary>…</details>`로 접습니다. summary에 모델·effort를 적으면 "AI가 쓴 부분"이 분명해집니다.
- 🔗 [Simon Willison](https://simonwillison.net/2026/Nov/9/details-summary/)

### 하드웨어 설계 에이전트: 데이터시트 근거 + 스크립트 검증 (Anthropic×Diode, 11/9)
- Claude가 스피커폰 등 기기 3종의 회로도·PCB·외형·펌웨어를 만들었고, 회로 수정 없이 동작했습니다. 다만 전기적 검증·인증은 거치지 않았습니다.
- **적용 팁:** ① 부품 판단은 데이터시트를 읽게 하고 ② 민감한 배선부터 처리하며 ③ 막히면 영역을 통째로 다시 하게 허용하고 ④ 맞춤 검사(외형 간섭, 공진 계산)를 스크립트로 짜게 하세요. 자동 검사 경고는 진짜 위반과 오탐으로 나눠 사람이 검토합니다.
- 🔗 [Anthropic Research](https://www.anthropic.com/research/claude-electronics-design)

### 밤새 맡길 땐 "자기 검증 봇"까지 요구하라 (개인 사례)
- 한 개발자가 Fable 5.2 사전 접근판에 긴 프롬프트 하나로 4인용 격투 게임 완성을 맡겼습니다. 에이전트는 밤새 대부분을 다시 썼고, 12개 스테이지를 헤드리스 브라우저로 직접 플레이하며 스크린샷을 검사하는 봇도 만들었습니다. 약 600회 요청, 3.4억 토큰이 들었습니다(작성자 추정).
- **적용 팁:** 목표·참고 자료·"기존 코드 폐기 허용"·"진행하며 커밋"을 한 브리프에 담고, 결과를 스스로 검사하는 수단을 만들라고 요구하세요. 재미·밸런스는 여전히 실제 사용자 테스트가 필요합니다. 이전 모델과 비교는 하지 않은 개인 경험담입니다.
- 🔗 [notesbylex](https://notesbylex.com/fable-5-2-one-shotted-my-nephews-dream-game)

### "100% AI 코딩" 1년 뒤, 아무도 코드를 이해 못 한다 (커뮤니티)
- r/ClaudeCode 글이 HN에서 화제였습니다. 댓글에서는 사람 리뷰를 빼면 이해도가 빠르게 떨어진다, 가치는 코드가 아니라 설계·이해에 있다, 모델이 바뀌면 지나치게 정교한 지시문이 오히려 해가 된다는 의견이 많았습니다. 원문은 직접 확인하지 못했고 HN 토론 기준입니다(2차).
- **적용 팁:** 핵심 모듈은 사람이 리뷰하고 설명할 수 있어야 머지하도록 규칙을 두고, 설계 결정은 문서로 남기세요.
- 🔗 [HN 토론](https://news.ycombinator.com/item?id=50433079)

### 스킬·MCP 서버를 설치 전에 정적 검사하라 (USB+, Show HN)
- 오픈소스 USB+의 `usb secscan`은 스킬이 선언한 설명과 실제 코드의 능력(자격 증명 접근, 네트워크 출력을 셸로 실행 등)을 비교해 선언되지 않은 것을 파일:줄 단위로 표시합니다. `usb mcprobe --yes`는 MCP 서버를 띄워 노출 도구 목록만 확인합니다.
- **적용 팁:** CI에서 `--baseline`으로 "새로 생긴 경고만 실패" 처리하면 도입이 쉽습니다. 별 2개 수준의 초기 프로젝트라 정확도 검증은 아직 없습니다.
- 🔗 [GitHub](https://github.com/PeepSick/usbplus)

## 🤖 새로운 모델

### Claude Fable 5.2 / Mythos 5.2 (Anthropic, 11/9)
- 가격 입력 $8 / 출력 $40 (100만 토큰당), fast mode는 $16/$80. Fable 5.1보다 출력이 최대 30% 빠르다고 합니다. FrontierSWE v2 69.9%(Opus 5.5는 62.3%) 등 회사 발표 수치입니다. Mythos는 검증된 사이버보안·생명과학 조직 전용입니다.
- 정당한 요청을 막는 비율이 5.1보다 약 55% 줄었고, preserved thinking이 모든 API 계정에 적용됩니다. 쓰는 중이면 연동을 점검하세요.
- 구독자는 11/16까지 Pro·표준 Team 좌석에서 주간 한도의 50%까지 Fable을 쓸 수 있습니다.
- 🔗 [Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-2) · [출시 혜택](https://support.claude.com/en/articles/17506494-claude-fable-5-2-launch-offers) · [Artificial Analysis](https://artificialanalysis.ai/models/claude-fable-5-2)

### Meta Muse Ember (11/9)
- Meta의 가장 작은·효율적인 모델. 컨텍스트 1M, 출력 최대 512K, 200K 이하 프롬프트 기준 입력 $0.10 / 출력 $0.50(100만 토큰당). Artificial Analysis Index 36으로 Haiku 5.5와 같다고 발표했습니다. 파라미터 수와 가중치 공개 여부는 나와 있지 않습니다.
- 🔗 [Meta](https://research.meta.ai/blog/muse-ember)

## ⚙️ LLM 서빙/인프라

- 8tx는 기밀(confidential) 추론·소규모 학습용으로 8t보다 지연이 최대 2배 낮고, 8i Max는 칩 2개를 한 패키지에 묶어 연산·SRAM·HBM 대역폭을 2배로 늘렸습니다. 출시 일정은 없습니다. KV 전송 지연과 TTFT를 90% 넘게 줄인다는 TPU Sync는 오픈소스로 공개됐습니다.
